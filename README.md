# 笑傲江湖 · 令狐沖

以 [Three.js](https://threejs.org/)（WebGL）製作的立體武俠冒險小遊戲。主角為金庸《笑傲江湖》中的 **令狐沖**。

## 遊玩方式

```bash
npm install
npm run dev
```

瀏覽器開啟終端顯示的位址後，點「開始闖蕩」。

| 操作 | 說明 |
|------|------|
| WASD | 移動 |
| 滑鼠 | 視角（點擊畫布鎖定指標） |
| 左鍵 | 出劍攻擊 |
| Shift | 輕功加速（消耗內力） |
| E | 與古廟／物品互動 |

## 任務

1. 在華山山林中尋找三卷 **獨孤九劍殘篇**
2. 可採靈芝補血、飲桃花酒回內力
3. 擊敗巡邏山賊
4. 殘篇齊全後前往 **華山古廟**，拜見風清揚完成闖蕩

## 技術

- Vite + Three.js（WebGL）
- 程序化角色／場景（古廟、竹林、寶塔、山霧）
- 第三人稱鏡頭、簡易戰鬥與任務流程
